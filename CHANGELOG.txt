CHANGELOG - MP Walkthrough & Shift Report
==========================================
History of changes since the original Gemini-generated prototype HTML.

v15 (current) - Home launcher (multi-tool platform begins)
------------------------------------------------------------------
- New Home tab (first of 5): the app now opens on a launcher with
  tool cards; the walkthrough is tool #1, a second tool slot is
  reserved ("coming soon").
- Home "Tonight" card: live hall status line (active hall, % ran &
  hung, open blockers), date/time, and backup freshness.
- Hash routing (#/home, #/walk, ...): screens survive reload and
  deep links like .../index.html#/walk jump straight into a tool.
- Stamp dock + hall tabs hide while on Home (clean launcher view);
  toast repositions.
- Nav buttons carry data-tab (programmatic switching from cards).

v14 - The rhythm & safety package (9 improvements)
------------------------------------------------------------------
- "End of night" button: archives the report, saves the baseline,
  then offers Copy report / Backup file in one overlay.
- Backup nag: tracks last backup; amber reminder + dot on the Report
  tab when missing or 3+ nights old.
- Screen Wake Lock (guarded; toggle in Preferences) - keeps the
  screen awake while the app is open where iOS allows it.
- Crew list edit mode: remove names (Edit button on Crew tab).
- Blocker date hidden by default (assumes today; "Date: today"
  button reveals the field for backdating).
- Report history collapses to the last 3 nights with "Show all".
- Sign-off line setting appended to the Team update.
- New graphite app icon (double-check mark, white + green).
- Text size setting (Normal/Large) in Preferences.

v13 - Simplify pass
------------------------------------------------------------------
- Replaced the hand-picked palette with Radix Colors dark scales
  (MIT, github.com/radix-ui/colors): 12-step scales for surfaces,
  accent, and all 5 status hues; solid left-edge status rails, status
  badges on step-9 solids, all colored TEXT on contrast-guaranteed
  step-11 tones (fixes WCAG AA failures of the previous palette).
- Open Props (MIT, github.com/argyleink/open-props) adopted:
  dark-mode shadow/elevation tokens (incl. inner top highlight),
  easing curves + durations, prefers-reduced-motion guard.
- Apple HIG craft pass: color-scheme dark (dark keyboard + native
  controls), iOS segmented-control styling for the cable scope row,
  iOS Settings-style section headers (13px/600 + count), concentric
  radii, press states with brightness dip at 120ms.
- "Stamp landed" glow: tapping a side now fires a 550ms glow ring in
  the status color (the tap feels alive).
- Hall progress bar replaced with an SVG progress ring + % counter
  (Apple/Lightning guidance: rings read as scoreboard, bars as
  loading).
- Dock glass recipe per backdrop-filter guidance (blur 20 /
  saturate 180%), toast and undo restyled to tokens.

v6 - "Midnight" visual redesign + field filters
------------------------------------------------------------------
- Full visual overhaul: deeper midnight palette, frosted-glass header
  and bottom dock, pill-style hall tabs, status cards with colored
  left rails + tinted backgrounds instead of full-color blocks,
  solid status badges, tabular numbers so row IDs align.
- Professional line icons (Lucide v1.59, ISC license, inlined) in the
  bottom nav, status dock, undo and jump buttons - replaces emoji.
- "Show: not finished yet" filter - hides fully-hung aisles and
  collapses finished sides to slim green check strips while walking.
- Jump-to-row: type a row number, it scrolls to and flashes that aisle.
- Hall progress bar (% of sides ran & hung) under the stats row.
- App now toasts "Update installed - close and reopen" when a new
  version downloads, and nudges the service worker to check for
  updates every time the app is reopened.
- iOS polish: long-press callouts suppressed on tappable elements.

v5 - Formal report rewritten to the hand-polished format
------------------------------------------------------------------
- "Team update (clean)" template: tokens-first lines
  ("111-113, 211-213, and 311-611: Ran and hung.") instead of
  status-first; single newlines everywhere (no blank lines).
- Mixed-cable sides get their own standalone lines with a full
  per-cable breakdown, most-advanced cables first:
  "1311: CAT6 ran; 144F and OCS staged."
- Uniform "ran" groups render as plain "Ran." (deliberate choice; the
  user's hand-edited sample had both "Ran." and
  "Ran 144F, OCS, and CAT6." styles).
- Notes flip "SUBJECT - Status (detail)" into
  "SUBJECT: Status (detail)." automatically
  (e.g. "HAC 17, Rows 33-36: Staged (8 hours per person).").
- Blocker lines auto-capitalized and period-terminated; hall prefix
  kept ("CB5 DH1: ...").

v4 - Bottom stamp dock + one-mention mixed rows + night rollover
------------------------------------------------------------------
- Status stamps moved from a top sticky card to a dock fixed at the
  bottom, directly above the tab bar: 6 status buttons (Hung / Ran /
  In Prog / Staged / Remed / Clear) + 4 cable-scope buttons.
- Mixed-cable sides now appear ONCE per report line (at the side's
  majority status, e.g. "1311 (Copper ran)") instead of being
  scattered across every status line (new mixedBase() majority rule).
- Night rollover: "Save tonight as baseline" on the Report tab, plus a
  dropdown to generate reports as "everything" (cumulative, default)
  or "only changes since baseline". Changes mode builds a synthetic
  halls copy where sides that did not move read as 'none'; sides that
  moved keep their FULL current state (effectiveHalls()).
- Baseline included in undo snapshots and JSON backups.

v3 - Rotate row view + formal template + blocker halls
------------------------------------------------------------------
- "Rotate Row View" button cycles 4 orientations: horizontal with
  11-side or 13-side on the left, or vertical with either side on
  top; the side legend arrows rotate with it; choice is remembered.
- New "Team update (clean)" formal report style (Team, / Shift
  Summary / "MP | hall" sections / Oxford-"and" token joins /
  "Blockers - <date>" section).
- Blockers gained an optional hall dropdown; rendered as
  "CB5 DH1: ..." prefixes in the formal report.
- Fixed empty "()" in the quick report's personnel line when no crew
  chips are active.

v2 (first GitHub Pages release) - full rewrite of the Gemini prototype
------------------------------------------------------------------
Everything below replaced or rebuilt from the original single HTML:
- Real site layout encoded from the Large Site Cable Installation
  Guide PDF: network rows 1-2; compute rows with pods of 8 rows
  (3-10 / 11-18 / 19-26); CB4 DH2 extends to row 36 (HAC area);
  EOR anchors at spot 11 and 13; middle SPOCS aisle not tracked.
  Halls preloaded: CB5 DH1 (pods 1-3), CB4 DH2 (pods 10-12 + rows
  27-36), CB4 DH4 (pods 10-12). Halls/groups/row counts editable
  in-app.
- Data model: per row, per side (11 = X01-X11, 13 = X13-X22), per
  cable (144F / OCS / CAT6), one status: Not started, Staged, In
  Progress, Ran, Ran & Hung, Remediation. Statuses carry over
  night to night.
- Stamp interactions: status brush + cable scope; tap side = stamp
  side; tap aisle number = stamp both sides; tap a cable pill =
  stamp one cable; range stamp (rows A-B); whole-pod bulk buttons;
  tap-again-to-clear toggle; 60-level undo.
- Live stats per hall (sides by status + per-cable progress).
- Crew chips with auto-counted SP headcount; dated blockers;
  areas of concern; tasks for tomorrow.
- Report compressor producing the site's row shorthand:
  "111-113, 211-213, 301-311, 501-511 & 601-611 - Ran and hung.",
  run compression ("711-1311 & 713-1313"), short/full/plain number
  styles, mixed-side notations. Templates: quick nightly report,
  crew/table style, boss roll-up (per hall, per cable, blockers with
  "(i)", tasks for tomorrow).
- PWA packaging: versioned service worker (cache-first precache +
  activate cleanup), web manifest, 180/192/512 icons, apple-touch-
  icon, viewport-fit=cover + safe-area insets, touch-action
  hardening, first-run install onboarding, storage.persist().
- Data safety: autosave to localStorage; one-tap backup via Web
  Share (files-only payload for the iOS quirk) with clipboard and
  download fallbacks; restore from file picker or pasted JSON;
  in-app report history.
- Fixes vs the Gemini prototype: working iOS clipboard fallback
  chain (Clipboard API -> hidden textarea + execCommand), real
  layout instead of fixed 26 rows, export/backup the prototype never
  had, service worker the prototype never had.
