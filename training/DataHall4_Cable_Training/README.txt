DATA HALL 4 CABLE INSTALLATION - BEGINNER TRAINING PACKAGE
=============================================================

HOW TO OPEN
1. Unzip the whole package first (Windows: right-click > Extract All; Mac: double-click the zip).
   Opening files from inside the zip will not work.
2. Double-click START_HERE.html. It opens in your web browser (Chrome, Edge, Firefox or Safari).
3. Click "Open the course". Start with Lesson 0 (the DRS).

Everything works offline. Nothing in the package needs the internet.

WHAT IS INSIDE
  START_HERE.html                  Landing page with links to everything below
  course/index.html                The interactive course (17 lessons, practice, final check)
  videos/                          17 narrated MP4 videos, one per lesson (125:27 total)
  videos/*.en.vtt                  Caption files, also gathered in videos/captions/
                                  (captions are also built into each MP4 as English subtitles)
  videos/captions/                 Same caption files, gathered in one folder
  videos/transcripts/              Plain-text transcripts with timestamps and chapter headings
  reference/Reference_Guide.html   Reference guide: glossary, connection tables, checklists, open items
  course/drs-explained/           DRS Explained: every covered DRS sheet rule by rule, with drawings
                                 (DRS_Explained.html web page + DRS_Explained.pdf to print)
  reference/Reference_Guide.pdf    Same reference guide, ready to print (US Letter)
  licenses/                        Font licenses (Inter, Lora: SIL OFL 1.1; DejaVu)

KEEP THE FOLDERS TOGETHER
The course plays the videos from the "videos" folder next to the "course" folder.
If you move or rename those folders, the course still works but the videos inside it will not play.
You can always play the MP4 files directly in any video player.

YOUR PROGRESS
The course saves your progress in this browser on this computer. A different browser or computer
starts fresh. You can reset progress on the course's Help page.

VIDEOS
- Narration is deliberately slow for new terms. Use the speed control in the course to go faster for review.
- In the course: chapters, captions (CC button), +/-10 s, speed, and a transcript that follows along.
- In other players (VLC, Windows Media Player, QuickTime): turn on subtitles; chapters appear in players that support them.

PHONES AND TABLETS
The course layout is designed for phones and tablets, but most phones cannot open local web pages
from a zip. Put the package folder on a web server or intranet as plain files (no server code needed),
or use the MP4 videos and the PDF directly on the device.

IMPORTANT
The current DRS (Deployment Requirement Sheet) says how the work must be done and must be on hand where
you work. Your site's cutsheet is the final word on any port. This training is built from the Large Site
Cable Installation Guide (cover Rev D, page footers Rev C, 10/8/2026) and the Fluidstack DRS sheets added
so far (01.00.00 to 01.00.03.01). It is a training aid, never a substitute for the DRS. Where the sources are
unclear or disagree, the course says so and tells you to ask your lead (see Reference guide > Open items).
